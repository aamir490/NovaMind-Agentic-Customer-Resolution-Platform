# Evaluations

This directory is reserved for reviewed datasets, rubrics, and results that assess future agent decisions and customer-resolution outcomes. No agent, evaluation dataset, evaluator, or model call exists today.

Future cases should distinguish correct information gathering, policy compliance, appropriate escalation, and verified outcomes from fluent text. Keep deterministic software tests in [tests](../tests/README.md). Select datasets and scoring criteria when the relevant milestone is authorized; Phase 0C adds no evaluation implementation.
